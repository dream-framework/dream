The Claim Being Tracked

DREAM (axiom A6) predicts: the micro-macro abyss IS the λq cliff, and λq is a structural property of the projection kernel. No amount of engineering improvement can push λq lower — the pixel is real.

Standard physics predicts: the boundary keeps moving with engineering progress. No structural floor.

Falsifiable test: if the resolution curve flattens (saturates) at some scale, DREAM is supported. If it keeps dropping with engineering improvements, DREAM is falsified.

How the tracker works

The scout (at pixel_tracker/scout.py) queries the arXiv API daily for recent papers in physics.optics and quant-ph with terms like "optical resolution", "nanoscopy", "interferometry", "displacement sensitivity". It extracts the smallest length-scale mentioned in each abstract and appends to a timeline.

A GitHub Actions workflow runs the scout daily and commits updates to pixel_tracker/records.json. The chart on this page reads that JSON and plots the timeline.

Caveats: scale extraction is heuristic (regex over abstract text) — false positives are possible. The DREAM kernel pixel at 10⁻²⁰ m is a theoretical claim, not a measured value. The tracker's job is to see whether published resolution records saturate, not to assert they do.
