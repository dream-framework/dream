The Claim Being Tracked

DREAM (axiom A6) predicts: the micro-macro abyss IS the λq cliff, and λq is a structural property of the projection kernel. No amount of engineering improvement can push λq lower — the pixel is real.

Standard physics predicts: the boundary keeps moving with engineering progress. No structural floor.

Falsifiable test: if the resolution curve flattens (saturates) at some scale, DREAM is supported — the flattening scale IS λq. If it keeps dropping with engineering improvements indefinitely, DREAM is falsified (no structural floor exists).

DREAM does NOT predict a specific value for λq. λq is treated as a measured constant of our kernel slice (axiom A4), not a derived one. The tracker watches whether the curve flattens somewhere — not at any pre-announced value.

How the tracker works

The scout (at pixel_tracker/scout.py) queries the arXiv API daily for recent papers in physics.optics and quant-ph with terms like "optical resolution", "nanoscopy", "interferometry", "displacement sensitivity". It extracts the smallest length-scale mentioned in each abstract and appends to a timeline.

A GitHub Actions workflow runs the scout daily and commits updates to pixel_tracker/records.json. The chart on this page reads that JSON and plots the timeline.

Caveats: scale extraction is heuristic (regex over abstract text) — false positives are possible. DREAM does not predict a specific numerical value for λ_q — the framework treats it as a measured constant (axiom A4), not a derived one. The tracker's job is to see whether published resolution records saturate somewhere, not at any pre-announced value.
