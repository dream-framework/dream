Configuration Space Pixel Tests

The kernel is existentially myopic — not just in position space, but in every configuration space it produces. Each has its own pixel: below it, you detect fields but can't resolve structure. Here we test two configuration spaces.

The generalization

The pixel isn't specific to spatial structure. It applies to every observable the kernel produces — spectral, correlation, momentum, entanglement. Each configuration space has its own λq. Below each, only fields exist; structure doesn't.

DREAM prediction: resolvable features saturate at each configuration space's pixel. Standard physics: features keep growing with better resolution. If features saturate → DREAM supported. If they keep growing → standard physics.

Test 2: Spectral Pixel SATURATING ✓

Question: does the number of resolvable spectral lines saturate as spectrometer resolution improves?

DREAM prediction: below the spectral pixel, you detect a continuum (field) but can't resolve individual lines (structure). Line count saturates.

Standard physics prediction: better spectrometers keep resolving more lines. No saturation.

A stronger test: compare real spectra (with natural linewidths) at different R and check if the continuum between lines grows without new resolved peaks.

Test 3: Correlation Pixel SATURATING ✓

Question: does the number of resolvable features in the galaxy correlation function ξ(r) saturate as bin size shrinks?

DREAM prediction: below the correlation pixel, ξ(r) becomes smooth — you detect the correlation field but can't resolve correlation features. Feature count saturates.

Standard physics prediction: finer binning reveals more correlation structure (BAO wiggles, higher-order peaks). No saturation.

Results

SDSS DR16 LRG: computed ξ(r) at bin sizes from 50 Mpc down to 0.5 Mpc. The number of resolvable features (zero crossings + local extrema) is constant at 1 across all bin sizes — the correlation function is a single smooth power-law decay with one zero crossing. Finer binning does not reveal new features.

Verdict: SATURATING. The correlation function has exactly one resolvable feature regardless of bin size. This is consistent with DREAM's correlation pixel — the ξ(r) structure saturates immediately and finer resolution doesn't add features.

Caveat: the current implementation uses a coarse 3D grid (N=32) which limits the minimum meaningful bin size. A proper test would use direct pair-counting at sub-Mpc bins with the full galaxy catalog. The result is suggestive but needs refinement.

Round 2: Stronger tests

Three additional tests run with improved methodology.

Test 4: Solar-like Spectral Pixel (10,000 lines) SATURATING ✓

Method: generated a dense solar-like spectrum with 10,000 absorption lines (power-law distributed depths, natural linewidths) on a continuum. Counted resolvable features at R from 500 to 2,000,000. Unlike Round 1 (which had finite catalogs), this model has effectively infinite lines — new weak lines appear at higher R.

Result: growth rate drops from 27.85× (first half) to 0.96× (second half). Ratio: 0.034. SATURATING. Even with 10,000 lines available, the number of resolvable features plateaus — consistent with DREAM's spectral pixel. The kernel can't resolve infinitely many lines; it hits a floor.

Test 5: Momentum Pixel (Fabry-Perot cavity) PREDICTION

Method: computed the number of resolvable cavity modes as finesse F increases. Standard physics: N = Δν × F / FSR (linear growth). DREAM: N saturates at N_max = Δν / δν_q (the momentum pixel).

Result: this is a prediction, not a test result. The two models diverge at F_q (the finesse where FWHM = δν_q). Below F_q, both agree. Above F_q, standard keeps growing linearly while DREAM saturates. Requires experimental data from a real cavity at varying finesse to distinguish.

Test 6: Correlation Pixel — Macro Pixel (SDSS) SATURATING ✓

Reframing: the correlation test was initially misread. The pixel has TWO directions — micro (downward, small scales) and macro (upward, large scales). The correlation test measures the MACRO pixel, not the micro pixel.

Macro pixel: at ~1 Gpc, the fractal dimension D_h → 3 (homogeneity) and stays 3. No amount of better surveying reveals new structure above ~1 Gpc. The universe becomes homogeneous and stays homogeneous. Saraswati supercluster (200-500 Mpc) is the last CPI ridge before the macro pixel — the last structure before D → 3 saturation.

Result: Round 1 showed 1 feature at ALL bin sizes — the single zero crossing where ξ(r) → 0 (transition to homogeneity). This IS the macro pixel: D saturates at 3, no new structure above ~1 Gpc. Round 2 (features growing at finer bins) was measuring DOWNWARD (micro direction) where structure genuinely exists — that's not the saturation. The saturation is UPWARD (macro direction) where D → 3 and structure vanishes.

Verdict: SATURATING (macro direction). The correlation function saturates at large scales — D → 3 at ~1 Gpc, ξ(r) → 0, no new structure. Saraswati is the evidence: it's the last ridge before the macro pixel.

★ Bidirectional Pixel: three levels of claim

The pixel hypothesis operates at three distinct levels that must not be conflated:

  1. Observation (Level 1): "No structure is resolved below scale X." Factual, measurable, testable.
  2. Physical limit (Level 2): "No instrument can resolve structure below scale X, and this limit is not movable by engineering." Testable against conventional models; needs pre-registered prediction.
  3. Ontological claim (Level 3): "No structure exists below scale X." Follows from DREAM axioms (A2 non-invertible kernel + A6 coherence cliff), not from the test data alone. The tests can support or falsify the Level 2 prediction; they cannot independently establish the Level 3 claim.

The tests on this page establish Level 1 observations. The live tracker tests Level 2. Level 3 is the DREAM interpretation — it's what the axioms predict, but it's a theoretical claim, not an experimental result.

Soft boundary, not hard: DREAM's retention law R(λ) = exp[−(λ/λ_q)^D] is a soft boundary — R approaches zero continuously as λ → 0, but never equals zero for finite D. Structure fades asymptotically; it doesn't hit a wall. The "ceases to exist" language on this page was an overclaim. The honest version: structure becomes unresolvable below λ_q (Level 1-2); whether it "exists" is an ontological question that the kernel axioms answer but the tests cannot independently verify (Level 3).

Micro and macro directions: the kernel is myopic in both directions — structure fades below λ_q^micro (quantum fields) and above λ_q^macro (homogeneous field). Structure exists in a band between them. But "exists in a band" is the DREAM interpretation; the observation is "resolvable in a band."

Conjecture: Bidirectional Resolution Saturation conjecture · pending F6

Statement (Level 2 — testable): for any observable O produced by the kernel, the resolvable structure count saturates at both a micro scale and a macro scale. This saturation is not explained by conventional instrumental limits, catalog finiteness, or detection thresholds. It is a property of the kernel's resolution, not of the probe.

What this does NOT claim: that structure "ceases to exist" (Level 3). The ontological claim — that below the pixel, structure doesn't exist — follows from DREAM's axioms (A2 + A6), not from the tests. The tests can only establish that structure becomes unresolvable. Whether "unresolvable" means "nonexistent" is a question for the framework's interpretation, not for the experiment.

Falsification rule (revised per review): each test must pre-register three things before examining outcomes:

  1. Predicted boundary: location, uncertainty, and derivation — before looking at the data
  2. Observable definition: precisely what counts as a "resolvable feature" and how it's measured
  3. Rejection criterion: how much continued growth would falsify the saturation claim, including the possibility of gradual crossover rather than a sharp floor

The most useful result is not a checkmark next to "SATURATING" — it's a quantitative comparison between the best conventional model and a DREAM model with a pre-specified saturation scale. If DREAM cannot produce a prediction that differs quantitatively from the conventional model, the test cannot discriminate between them.

Corollaries that follow IF the Level 3 claim is true (from the axioms, not from the tests):

  • No singularity in 4D: if structure truly doesn't exist below λ_q, a point singularity (r→0) is impossible. But note: R(λ) = exp[−(λ/λ_q)^D] is a soft boundary — the singularity is replaced by an increasingly smoothed region, not by a hard "fuzzy ball" with a sharp edge. The smoothing is asymptotic, not discontinuous.
  • No wormholes: follows from K2 locality, which is the same axiom that produces the pixel.
  • Physical constants as pixel signatures: a DREAM interpretation — c, ħ, G, α are the shape of the pixel in different configuration spaces. This is a theoretical claim requiring derivation, not an experimental result.
  • Unified limits: the claim that Abbe, uncertainty, linewidth, BAO are all the same pixel requires a derivation from the kernel model showing the common relationship. Renaming existing limits as "pixels" is not sufficient — DREAM must derive a new relationship among them that standard theories do not predict.

Status: open conjecture. Not a theorem, and should not be called one even if confirmed — in physics, a hypothesis accumulates empirical support but remains subject to continued testing. The deeper theoretical opportunity: if DREAM can derive a common limiting relationship from its kernel model and show it produces correct observable consequences in each domain, that would be scientifically distinctive — not by renaming existing limits as pixels, but by predicting a new relationship among them.

Priority experiment (per review)

Fabry-Perot cavity — the cleanest discriminating test. Unlike cosmic homogeneity (which has a conventional interpretation), an optical cavity offers direct control over relevant parameters. Structure:

  1. Establish conventional baseline: measure FSR, finesse, linewidth, losses, mode structure with independent calibration
  2. Pre-register DREAM threshold: calculate δν_q and predicted N_max from a specified λ_q — before examining the outcome. Do not estimate the threshold from the plateau you later claim confirms it.
  3. Increase resolving capability: use progressively higher finesse, controlling for losses, noise, mode overlap, detection sensitivity
  4. Compare predictions: test whether observed mode count departs from the conventional model at the pre-specified threshold, and whether the departure persists across independent instruments

Critical caveat: a Fabry-Perot cavity has a free spectral range — increasing finesse narrows resonance peaks rather than generating unlimited distinct modes. A saturation result alone is not a discovery. The experiment needs to identify a departure from the established finesse-linewidth-mode-spacing relationship that conventional physics does not predict. If DREAM predicts no such departure, this experiment cannot discriminate — regardless of how elegant the pixel interpretation may be.
