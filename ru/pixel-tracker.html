Отслеживаемое утверждение

DREAM (аксиома A6) предсказывает: микро-макро пропасть ЕСТЬ обрыв λq, а λq — структурное свойство проекционного ядра. Никакое инженерное улучшение не может сдвинуть λq ниже — пиксель реален.

Стандартная физика предсказывает: граница продолжает двигаться с инженерным прогрессом. Никакого структурного пола нет.

Фальсифицируемый тест: если кривая разрешения выравнивается (насыщается) на каком-то масштабе — DREAM подтверждается, и масштаб выравнивания и есть λq. Если продолжает падать с инженерными улучшениями бесконечно — DREAM фальсифицирован (никакого структурного пола нет).

DREAM НЕ предсказывает конкретное значение λq. λq — измеренная константа нашего среза ядра (аксиома A4), а не выведенная. Трекер следит, выравнивается ли кривая где-то — а не на заранее объявленном значении.

Как работает трекер

Поисковик (pixel_tracker/scout.py) ежедневно запрашивает API arXiv о недавних статьях в physics.optics и quant-ph с терминами вроде «оптическое разрешение», «наноскопия», «интерферометрия», «чувствительность к смещению». Извлекает наименьший масштаб из аннотации и добавляет в таймлайн.

GitHub Actions запускает поиск ежедневно и коммитит обновления в pixel_tracker/records.json. График читает этот JSON и строит таймлайн.

Оговорки: извлечение масштаба эвристическое (регулярные выражения по тексту) — возможны ложные срабатывания. DREAM не предсказывает конкретное числовое значение λq — рамка рассматривает его как измеренную константу (аксиома A4), а не выведенную. Работа трекера — увидеть, насыщаются ли опубликованные рекорды где-то, а не на заранее объявленном значении.
