The story in one sentence

T7.1 says: S2 is the local law of retention, but the global curve is a piecewise composition of S2 regimes — the kernel enters different regimes at reproducible fractional positions.

This toy fetches real live data, fits 6 competing models head-to-head, and shows you exactly when piecewise S2 wins (and when it doesn't).

Layman analogy
Imagine a long road trip. Same car, same driver, same road — but the speed limit changes at every town. Your GPS log shows piecewise behavior: 70 mph on the highway, 30 mph through town. The journey is one continuous drive, but the speed log has sharp transitions at reproducible milestones. DREAM's retention law behaves the same way.

What the 6 models say (math)

1. Single S2:
R(λ) = exp[−(λ/λq)D]

3 params (λq, D, plus amplitude fixed at 1). The local retention law.

2. Piecewise 2-S2 (T7.1):
R(λ) = S2(D₁, λq,1) for λ<λ*
R(λ) = A₂·S2(D₂, λq,2) for λ≥λ*

6 params. The T7.1 refinement: same kernel, different effective parameters per regime.

3. Power Law:
R(λ) = A·λ−α

2 params. Scale-free decay — a leading non-S2 alternative.

4. Biexponential:
R(λ) = A₁·exp(−λ/l₁) + A₂·exp(−λ/l₂)

4 params. Two-pool decay — the standard non-stretched alternative.

5. Lognormal:
R(λ) = (A/λ)·exp[−(ln λ − μ)²/(2σ²)]

3 params. Peak-then-decay — a non-monotone alternative.

6. Gaussian:
R(λ) = A·exp[−λ²/(2σ²)]

2 params. Special case of S2 (D=2) — a "no-stretch" baseline.

How the fit works (technical)

1. Compute the autocorrelation function R(τ) of the live series.
2. Use the ACF as the retention curve R(λ), with λ = lag in native units.
3. Fit each model via Levenberg–Marquardt with multiple initial guesses; keep the best RSS.
4. Compute AICc = 2k + n·ln(RSS/n) + 2k(k+1)/(n−k−1).
5. For piecewise 2-S2, search 7 candidate breakpoints λ* ∈ [25%, 75%] of the t-range; report the best.
6. The piecewise fit uses continuity at λ* (A₂ absorbed by the constraint).

How to read the result

If Piecewise 2-S2 wins (ΔAICc ≤ −4 vs single S2): the kernel is crossing a regime boundary in this dataset. The transition scale λ* is reproducible evidence for multi-regime structure.

If Single S2 wins: this dataset is well-described by one regime — no transition needed. (Common for clean physical signals.)

If Power Law wins: this dataset may be scale-free rather than S2-shaped. T7.1 doesn't apply — but the framework accepts this as a falsification pressure, not a contradiction.

If Biexponential wins: two-pool decay fits better than piecewise S2 — the dataset has discrete mixture structure rather than regime transition.

The honest framing: T7.1 is empirically supported when piecewise S2 systematically wins across many unrelated datasets, with transitions that cluster at reproducible fractional positions. A single dataset is anecdote; the 25-dataset registry (binomial p = 3.4×10⁻¹⁸) is the actual evidence.
