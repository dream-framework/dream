Test 13 — Pinhole Array / Multi-Aperture Hypothesis

If the kernel is a pinhole array (each sector has its own aperture projecting onto a shared screen), all sector cutoffs should reduce to a single shared λ_q via some function of α. Test: try f(α) = α, √α, ∛α, etc, check if implied λ_q agrees across sectors.
VERDICT: NEGATIVE
Best candidate f(α) = α^(1/2) gives implied λ_q values that scatter by a factor of 2946472 across all sectors (log10 spread = 6.5 decades). No single f(α) reconciles all 4 sector cutoffs with a shared λ_q. The multi-aperture hypothesis is FALSIFIED: the kernel is NOT a pinhole array with a shared screen. Each sector must have its own kernel (or the multi-aperture analogy is wrong). Sub-finding: weak + strong + gravity DO cluster tightly for f = α^(1/2) (within factor ~12, geometric-mean λ_q ≈ 10⁻¹⁵ m, close to QCD scale), but EM is the outlier by 1-2 orders of magnitude. Suggests either (a) a partial multi-aperture model (non-EM sectors share a screen, EM has its own), or (b) the EM focal hierarchy (r_e:λ̄_e:a_0 = α:1:α⁻¹) is a QED coincidence, not a kernel feature.
