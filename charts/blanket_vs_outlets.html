Test 16 — "Blanket" vs "Myriad Outlets, Same Function"

Two new candidate kernel analogies. (A) Blanket: one uniform field, same parameters (D, λ_q) everywhere. (B) Myriad outlets, same function: many sector-specific outlets, all implementing the same retention function (S2), with different parameters per outlet.
VERDICT: MYRIAD OUTLETS
Form invariance = 60.9% (r² > 0.9) — S2 form is broadly applicable across sectors (the 'same function' part). BUT parameter variance is HIGH: D CV = 0.994, D range = [0.047, 9.980] (211× variation), and 85.7% of cross-domain KS tests are statistically distinguishable (p < 0.05). ANOVA η² = 0.081 — 8.1% of D variance is between domains. D values DIFFER systematically by sector (e.g., crypto D≈1.47, cultural D≈0.51, ecological D≈0.90). The kernel is NOT a single uniform blanket (parameters vary too much), but the S2 functional form IS broadly applicable. This supports the MYRIAD OUTLETS, SAME FUNCTION hypothesis: the kernel has many sector-specific 'outlets' that all implement the same retention function (stretched exponential S2), but each outlet has its own effective parameters (D, λ_q).
